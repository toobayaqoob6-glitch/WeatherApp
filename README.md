# 🌤️ Tooba's Weather App

A lightweight desktop weather application built using **Python**, **Tkinter**, and the **OpenWeatherMap API**. This app allows users to select or search major cities across Pakistan and view real-time meteorological data including climate status, descriptions, temperature, and atmospheric pressure.

---

## 🚀 Features
* **Interactive UI:** Designed using Python's `Tkinter` and `ttk` libraries with a custom layout and styling.
* **City Selection Dropdown:** Includes a comprehensive pre-loaded list of major cities and regions across Pakistan.
* **Real-Time API Integration:** Fetches live data asynchronously using the `requests` library connected to OpenWeatherMap REST API.
* **Live Weather Metrics:** Displays:
  * Weather Climate (e.g., Clear, Clouds, Rain)
  * Detailed Description (e.g., broken clouds, light rain)
  * Temperature in Celsius (°C)
  * Atmospheric Pressure (hPa)

---

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **GUI Framework:** Tkinter, Tkinter.ttk
* **HTTP Requests:** Requests library
* **API:** OpenWeatherMap API
